# Домашнее задание к работе 5

## Условие задачи
Создать программу вычисления указанной величины. Результат проверить при заданных исходных значениях.

Выражение для вычисления:

g = y^(x+1) / (∛|y − 2| + 3) + (x + y/2) / (2·|x + y|) · (x + 1)^(−1/sin z)

Контрольный пример: при x = 12,3·10⁻¹, y = 15,4, z = 0,252·10³ результат g = 82,825623.

**Вариант 14**

## Алгоритм

1. **Начало**
2. Ввести исходные данные:
    `x`, `y`: вещественные числа;
    `z`: угол в радианах.
3. Вычислить первое слагаемое:
    `a` = `y`^(`x` + 1) / (∛|`y` − 2| + 3)
4. Вычислить второе слагаемое:
    `b` = (`x` + `y` / 2) / (2 * |`x` + `y`|) * (`x` + 1)^(−1 / sin(`z`))
5. Вычислить результат:
    `g` = `a` + `b`
6. Вывести значения `x`, `y`, `z` и результат `g`.
7. **Конец**

## Реализация программы

```c
#define _CRT_SECURE_NO_DEPRECATE
#include <stdio.h>
#include <math.h>
#include <locale.h>

int main()
{
    setlocale(LC_ALL, ".UTF-8");

    double x, y, z;

    printf("Введите x, y, z: ");
    scanf("%lf %lf %lf", &x, &y, &z);

    double a = pow(y, x + 1) / (cbrt(fabs(y - 2)) + 3);
    double b = (x + y / 2) / (2 * fabs(x + y)) * pow(x + 1, -1 / sin(z));
    double g = a + b;

    printf("При x = %.2f, y = %.2f, z = %.2f\n", x, y, z);
    printf("g = %.6f\n", g);

    getchar();
    getchar();
    return 0;
}
```
